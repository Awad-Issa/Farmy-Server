Digital Sheep Management System 
● Technologies: Java Spring Boot, React, MySQL, MongoDB, AWS, REST APIs, Lombok 
● Description: A web application for managing sheep farms, tracking sheep details, 
relationships, and livestock data. 
● Features & Role: 
○ Ewe, Ram, Lamb Management: Automatic gender assignment, mother-child 
relationships, and offspring tracking. 
○ Pregnancy & Health Tracking: Manage pregnancies, health status, and weights 
of sheep. 
○ Data Management: CRUD operations for sheep, stored procedures, and 
validation for accurate record keeping. 
● Achievements: Designed a full-stack solution connecting backend and frontend, 
implemented complex relationship logic between sheep entities, and ensured scalable 
data handling on MySQL/MongoDB with AWS deployment.
